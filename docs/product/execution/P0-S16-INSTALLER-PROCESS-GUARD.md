## 问题与修改

旧 Tauri NSIS 检查只登记桌面 EXE；静默路径含 Restart Manager 强制停止分支，升级页可先运行旧卸载器。用任务专属小型网关进程复现：旧检查返回 0 并继续，网关仍活着。

新安装模板固定于 Tauri CLI 2.12.3，保留上游 MIT 许可与 SHA256，改为原位更新，不调用旧卸载器。安装先于 WebView 前置步骤、程序写入前、卸载删除前，都检查精确安装目录的桌面和网关路径。忙碌返回 1618，检查失败返回 1603，不关闭任何进程。用户通过现有“等待后退出”排空请求；独立网关由其所属入口停止。所有模式拒绝降级，返回 1638。

这不是两个 EXE 的原子更新事务。新进程可能在检查后启动，文件替换中断、忽略文件写入错误、恢复路径仍需下一批验证。现有 IPC 严格匹配产品版本，不能仅凭源码据此宣布中断矩阵通过。
