# P1-S05 模型健康记录基础（dev.11/schema5，未安装）

本批在禁止电脑控制下继续非UI开发。用户安装/资料未改，不启动桌面、截图、读取窗口或做原生UI验收；没有真实上游调用、收费生成、密钥读取或新环境/worktree。

新增Rust核心model_health操作性记录，将目录曾见模型、真实推理成功、失败原因和5分钟有效期分开。目录成功不会让模型获得推理Ready。有效期严格小于300000ms，到达边界或系统时钟倒退不作为新鲜成功；后来的失败阻止选用，过时成功不能覆盖较新失败，较新成功可以恢复。记录不含请求/响应正文、凭据或原始错误体，视图只返回来源、模型、年龄、状态和枚举失败。

连接身份指纹包含供应商UUID、协议、URL和凭据引用代次，不含密钥；旧URL/凭据代次完成的结果不能写到新代次。模型移除/供应商删除清理对应操作记录，连接改变清理旧记录；模型排序、供应商临时停用不抹掉事实，停用期间不作为可选渠道。配置不可变快照和修订不因健康观测递增，已有历史配方也不改写。

schema5增加独立model_health表，沿用既有排他迁移/一致备份/journal；历史快照JSON字节保持不变。运行时健康读写只接受已经存在且owner/schema正确的库，持共享维护锁与短事务，既不初始化迁移也不接触凭据库。源代码迁移只在独占fixture验证，没有升级用户schema3库。
