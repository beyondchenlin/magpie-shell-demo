## 真实链路与协议

ChatView → 受限send_chat/cancel_chat → Rust原生适配器 → 认证loopback网关 → 有效配置中首个匹配模型的启用供应商 → 同一流返回界面。供应商凭据和本机令牌留在Rust，新通道只传文字与状态。内置对话要求desired等于effective，并附expected revision；网关同时钉住修订、目标和快照凭据，在途请求不因普通apply改道。没有第二条直连云端的聊天路径。

GET /v1/models列出启用的手动配置模型并去重，不作为上游健康证明。POST /v1/chat/completions支持文本role/content、单候选和有限生成参数，含非流式/SSE；tools、多模态和其他未实现字段明确拒绝，不静默剥掉。Tagma命名空间继续保留。

共享SSE解码器处理任意网络分片、UTF-8、CR/LF、多事件及结束帧。缺结束帧/格式错误/上游错误均失败并保留已收到文字；length/content_filter结束有可见说明。未完成轮次不当作完整助手回复进入后续上下文。对话仅在当前窗口内存保留。

单事件256KiB、总回复8MiB、桌面文字256KiB，请求体128KiB。8并发名额在读取请求体前取得，直到下游body被消费/丢弃才释放，没有无限队列。连接10秒、响应头30秒、流空闲30秒、总预算120秒。生成无自动重试、不跟随重定向、不自动读取环境代理，保留TLS验证；拒绝不可信Origin/Sec-Fetch/Host，CORS不承担鉴权。管理命令不挂HTTP数据面。

停止取消本窗口原生请求并关闭对应loopback及上游连接；覆盖首段前、中途、离开对话页。外部客户端请求不会因桌面页面切换取消。注册RAII收尾，原生窗口仅一个聊天并发；若取消早于Started，前端在Started后补发，避免起步竞争。
