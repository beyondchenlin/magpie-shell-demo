# 本机开发与磁盘空间约束

来源：用户本轮提供的 AGENTS.md 指令。以下为跨聊天执行必守摘要；用户原始指令与实际 AGENTS.md 有更细要求时同样遵守，用户明确指令优先。

1. 安装依赖、下载模型、创建 worktree、复制环境、全量构建前，检查目标盘与系统 Temp 盘可用空间，并查看现有仓库、worktree、缓存与运行环境；优先复用。
2. 任一相关盘 <20 GiB 时提示且优先复用；<10 GiB 时暂停预计新增 >1 GiB 操作，先缩小范围或回收本任务可重建产物。只读、小改动、安全清理继续，不转移到另一空间不足盘。
3. >1 GiB 操作记录绝对目标目录、估计峰值、复用方式、收尾方案；工作空间容纳峰值后保留至少10 GiB。不为常规已授权可逆动作反复询问。
4. 新 worktree 前 git worktree list --porcelain，并查 Codex 当前附件；仅隔离/并发确需时创建，通常最多额外一个。记录用途、主仓库、路径、结束条件；不每个测试创建新环境。
5. 保持原锁文件/包管理器，复用官方缓存；禁止跨树共享可写 node_modules/.venv/target/.next 或硬链接工具可改写文件。隔离构建目录有界且结束回收。
6. 模型下载先核对现有路径/版本/hash，引用现有库，不因目录不同复制模型或完整 CUDA/Python。
7. 测试使用独占临时目录与 finally/teardown；不混真实数据；遗留持续增大先修清理，失败只保留最小复现/必要日志/清单。大数据测试优先流式/稀疏/小样本。
8. 检查按改动范围，必要验证通过后仅新改动/失败/未解决风险才重跑扩大。新日志默认单文件20 MiB、最多5份；不重复保存巨大目录清单。
9. 截图和验收先规划证据容量，仅重跑受影响范围；保留版本/结果/必要失败证据，不复制全基线，不擅删旧证据。逻辑大小与硬链接去重物理占用区分。
10. 构建输出、包、测试数据库、缓存不得进Git；临时产物与交付/恢复资料可区分。
11. 清理仅本任务明确拥有、可重建、未使用内容。先列绝对路径/用途/大小/安全依据；不是名称含 temp/old/backup/verify 就可删。
12. 删除前验证解析绝对路径在精确边界内，检查重解析点/联接/符号链接、进程引用、文件锁、近期写入。无法确认或使用中跳过。Windows 用单一 PowerShell 与 -LiteralPath，禁止跨shell递归删除。
13. 工作树收尾检查dirty/untracked/ignored重要文件、独有/未推送提交、其他聊天使用与外链；Codex树用archive_worktree，手工树保全后非强制 git worktree remove，不删整个根、不强删脏树。
14. 定向官方缓存回收优先；禁止 docker system prune -a --volumes、批量删环境/模型、清空Temp、删除聊天/数据库、修改分页休眠、停止别人服务。
15. 归档只存源码差异/独有提交/必要证据/恢复说明；不打包依赖/构建缓存/模型。回滚包标用途/负责人/复查日；未知用途旧备份不删。确需保留可运行包时剔除纯编译cache和测试临时输出。
16. 收尾报告新增/保留worktree、临时回收及仍须保留目录。大空间操作报告前后可用空间，区分逻辑/净释放，考虑硬链接/压缩/稀疏/并发写。
17. 这些约束不授权定时清理、删除他任务产物或跳过必要验证。当前定时任务只监督本次PRD实现。
