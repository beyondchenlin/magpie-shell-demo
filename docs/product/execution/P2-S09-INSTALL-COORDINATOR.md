# P2 安装流程接线

2026-10-19，接续 P2-S08 `b2d3efe`。本批继续复用 dev.40 隔离实例与原构建缓存，无新桌面候选、无安装器重测、无定时任务。

新增 `tagma-runtime::pack_install::PackInstaller`，将先前各层串成可执行流程：

1. 以宿主信任根验证签名清单，绑定真实配置 UUID、当前修订及目标平台，返回完整权限/资源声明和两盘空间计划。只保存最多4份、有效5分钟的待确认记录，不下载、不执行。
2. 确认只接受宿主生成的 review UUID 和清单 SHA256；记录使用一次即消费，变更、过期或配置修订冲突拒绝，失败不会透明重放。
3. 再验签及两盘空间，生产下载仅 HTTPS，系统证书验证，禁代理、重定向和自动重试；5秒连接/120秒请求上限，不接受前端 URL 覆盖、请求头、证书绕过或路径。
4. 流式写入原有有界暂存器；下载之后再次检查信任期限和空间，再完成 checksum、解包、准备目录发布、实际进程健康检查，最后事务切换活动版本。进度只报告实际到达的阶段。
5. 单安装许可同时覆盖网络与阻塞写入/解包。取消等待所属 worker 回收，失败清理本次未发布下载/解包临时文件；若已发布准备目录但未激活，则保留可核查准备记录，不伪造已安装。

空间计划包含现有文件逻辑大小（最多20,000条、2秒扫描限制），已占用空间不重复扣除；目标与临时盘均重新观测并保留10GiB余量。目录拒绝符号链接和 Windows 重解析点；仍不承诺抵抗已控制同一用户账户的文件系统攻击。

## 实际验证

3项定向测试显式 `--ignored` 执行通过，0失败；不是默认忽略就记成功：

- 宿主审阅→实际本机 HTTP 字节下载→校验/解包→独立进程健康→登记→实际进程中文试跑，阶段顺序完整，下载临时文件归零，同一审批不可重放。
- 摘要变化、已消费审批、配置修订变化均在下载前拒绝，凭据设施没有读取/写入。
- 下载中取消及同长度损坏内容均不激活，配置仍为0，下载与准备目录为空。

首轮2项失败源于测试 listener 的非阻塞模式被 Windows 接受套接字继承，测试服务未正确读写完整响应；显式将接受套接字切回阻塞后3项通过，未放宽生产校验或 TLS。最终 runtime 全 targets Clippy `-D warnings` 通过。该测试专用 HTTP 地址替换仅由 `cfg(test)` 编入单元测试程序，正式库及桌面构建没有此字段；无证书跳过代码。

命令：`cargo test -p tagma-runtime --lib pack_install::tests --locked --offline -- --ignored --nocapture`；复用 P2-S08 已核验 helper。后端测试输出说明本次结果，**不等于真实 HTTPS 发行源、ReachFlow 或桌面原生通过**。
