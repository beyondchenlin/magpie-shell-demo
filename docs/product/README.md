- [当前 PRD](TAGMA-PRD-v0.3.md)：用户目标、功能要求、架构边界、分期和验收。
- [停笔功能交接（2026-10-19）](execution/FEATURE-HANDOFF-2026-10-19.md)：已验界面功能、页面入口、最新候选启动限制、未完成项与恢复顺序；开发和调度均暂停。
- [两轮审查记录](TAGMA-PRD-v0.3-REVIEW.md)：审查输入、问题、修订与剩余产品决策。
- [历史 PRD v0.2.4](reference/TAGMA-PRD-v0.2.4-2026-10-15.md)：2026-10-15 原文快照，不作为与新稿并列任选的标准。
- [当前 CIS](../CIS-CONTROLS.md)：现有控件与交互规范；产品 IA 变更不自动获得旧复刻验收通过状态。

历史 PRD 取自 [原交接分支](https://github.com/beyondchenlin/magpie-shell-demo/blob/docs/handoff-2026-10-16/docs/product-context/tagma-prd-2026-10-15.md)，于 2026-10-17 通过 GitHub 连接器读取。参考副本保留原文中的旧环境路径；新产品开发不依赖这些路径存在。

本目录不表示功能已经实现或已发布。v0.3 中建议改变旧冻结行为的事项见 PRD 第 3 节。
