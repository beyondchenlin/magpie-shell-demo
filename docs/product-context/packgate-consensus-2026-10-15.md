# Tagma / PackGate 共识冻结（讨论版 · 2026-10-15）

> 先个人、后服务器；**地基优先**。本文冻结方向；详细 PRD 见 `/workspace/tagma-prd-2026-10-15.md`（**v0.2.4**）。

## 1. 产品一句话

**Tagma（塔格玛 · 特战队）**（工程代号 PackGate）= **轻量 Agent 入口**（接各家 API）+ **路由网关**（组合小队以 `tagma/<ascii_slug>` 出现在选模型列表）+ **按需加载的本地队员（重型模块 / Skill Pack）**。  
学 LocalAI 的「小核心、用到再装」，**不做**本机千问级大模型服务器，**不 fork / 内嵌 LocalAI 全家桶**。

**地基优先：** 先做透壳主路径 + 真网关/组合/用量 + 运行时契约与 **一个**验证队员（ReachFlow）；其余队员进插件目录，松耦合，非近期关键路径。

## 2. 两版发行（已定）

| | 个人版（现在） | 服务器 / 局域网版（以后） |
|--|----------------|---------------------------|
| 形态 | 桌面原生**单安装包**（壳+网关 **sidecar 两进程、同包**；Win/Mac/Linux，Tauri） | Docker Compose |
| Docker | **不需要** | **默认用** |
| 谁运维 | 普通用户点安装包 | 会 Docker 的人自行解决镜像/网络 |
| 能力 | 同一套网关 + 队员；重队员仅桌面跑 | 同一套；多人经网络打 API |
| 网页 | 壳预览 / 假数据或远端网关；**不跑重队员** | 管理面可挂在服务上 |

国内个人：原生包 + 国内 CDN 即可。  
国内服务器：以后用国内镜像仓库即可；不在个人版里解决 Docker 翻墙。

## 3. 三层能力（融四套软件的「能力」，不叠四个壳）

| 层 | 学谁 | 用户感知 |
|----|------|----------|
| L0 轻壳 | CC Switch | 供应商 / 薄 Skill / MCP 写回各 Agent |
| L1 网关 | Magpie + New API 用量味 | 选模型、组合小队、渠道、流量统计 |
| L2 队员 | LocalAI「按需单元」 | ReachFlow 验证契约；其余 TTS/ASR/剪辑/… 插件化热加载 |

## 4. 组合小队（迷你 MoE · 产品层）

用户可把 **队员（剪辑/爬取/财务…）+ 可选 LLM** 配成一份配方，**起展示名 + ascii API slug**，以 `tagma/<slug>` 出现在大模型选择列表。  
云模型保留上游原名（无 `tagma/` 前缀）。  
不选 LLM 时：优先用已配置的云渠道当「脑」（`first_cloud`）；可选很轻的 Local Brain Pack（按需下），**默认安装包不塞大模型**。

## 5. 命名

- 对外品牌：**Tagma** / 塔格玛 / 特战队

- 薄：`Skill`（SKILL.md）  
- 胖：队员 / 重型模块（工程 `Skill Pack` / `pack:`）  
- 对外叙事可用「迷你混合专家」；对内是队员路由 + 组合配方  

## 6. 明确不做（一期 / 个人版）

- Fork 或内嵌 LocalAI；默认预置大参数本地对话模型  
- 一期 P2P / 模型分片  
- 个人版依赖 Docker  
- 网页版跑重队员  
- 把四个产品的完整 UI 原样叠进一个壳  
- 地基未稳前并行铺开一长串内容队员  
- 用 C++ 重写核心；核心要求用户预装 Python  
- 整仓拷 PI-Desktop；为内置 Agent 推迟地基；近期把「抢 Codex 日活」当关键路径  

## 7. 封闭 Agent 逃生舱 + 三入口

豆包工作等不能改 base_url 的：用 **Skill / MCP 桥**接入 Tagma（同 ReachFlow 对外 Skill 思路）。

**对等三入口（已冻结）：** 同一运行时可经 **Skill · MCP · `tagma` CLI** 调用；另加 OpenAI `/v1` 给可改 base_url 的 Agent。桌面壳是管理面，不是唯一入口（PRD §5.4 / G7）。

## 7b. 语言栈（已冻结）

- **核心（壳+网关）**：Rust（Tauri）+ React — **不**改写成 C++  
- **重型队员**：鼓励 native / C++（音频对标 YoVoice）；Python worker 允许但非音频首选  

## 7c. 内置 Pi 系 Agent（长线 · 已冻结）

打开 Tagma 即可用的 **Pi 系 harness**（学 LocalAI 内置 Agent / earendil-works/pi）：脑走网关；对内控制 MCP（人话管队员/供应商/用量/小队，确认门）；**不**整仓拷 PI-Desktop；**独立长线、不挡地基**；P0 对话可假。详见 PRD §5.5 / G8。

## 8. 体积态度

核心尽量轻（几十～几百 MB 更理想）；**不硬卡上限**；重能力全部按需下队员包。
